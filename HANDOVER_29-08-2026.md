## Arquitetura & decisões técnicas

| Decisão | Escolha | Motivo |
|---------|---------|--------|
| Estilos do website | SCSS (não Tailwind) | Migrado durante desenvolvimento |
| Estilos do dashboard | Tailwind CSS | Shadcn/ui compat |
| Pagamentos | **Asaas** (substituiu Stripe) | Provedor brasileiro, PIX + parcelamento |
| Upload de gift images | Supabase Storage | Simples para MVP |
| Upload de cápsula | Cloudflare R2 | Zero egress, custo mínimo para mídia pública |
| WhatsApp | **Evolution API v2** (substituiu Meta Cloud API) | Sem conta Business, zero custo |
| Infraestrutura WhatsApp | Oracle Cloud Free Tier + Docker | Gratuito permanente |
| Auth dashboard | Supabase Auth (email/password) | Acesso restrito ao casal |
| Auth feed | UUID na URL + validação de presença | Sem senha para convidados |
| Router dashboard | TanStack Router (code-based) | Evita `routeTree.gen.ts` auto-gerado |
| Supabase CLI | devDependency (`supabase` npm) | Via `pnpm supabase` sem install global |
